\section{The Idea in One Paragraph}
Textbook finance says prices reflect everything, risk is constant, and returns are
unpredictable. Decades of evidence say otherwise, and the mismatches are recurring,
studied patterns called \textbf{anomalies}.

\begin{opp}
An anomaly is just an opportunity seen from the other side: the same crack academics
flag as ``the model is wrong here'' is where a careful observer might find an edge.
This project makes three such anomalies measurable, \textbf{fuses them into a single
directional read}, and explains it.
\end{opp}

\section{The Three Pillars (the signal sources)}

\subsection{Pillar 1 — Macro Factor \& Lag Regression}
\textbf{Question:} Which macro forces move an asset, and with what delay? \\
\textbf{Method:} Monthly OLS of the asset's return on eight factors (VIX, oil, gold,
dollar index, 10-yr yield, Fed Funds, inflation, unemployment) at lags 0--3, plus
Granger causality and a lagged-correlation heatmap. Factors are \textbf{z-score
standardised} before fitting, so coefficients are comparable ``standardised betas''
— the effect per 1-SD move. VIX enters as a log-change for stationarity. \\
\textbf{Current:} \tk{\textasciicircum{}GSPC} R² = \textbf{0.687} (adj.\ 0.585);
Granger runs 32 tests, \textbf{6 significant}.

\subsection{Pillar 2 — GARCH \& Volatility Clustering}
\textbf{Question:} How does risk change over time, and are crashes under-estimated? \\
\textbf{Method:} GARCH(1,1) with Student-t errors on daily returns; Ljung-Box on
squared returns for clustering; Jarque-Bera and a QQ plot for normality. \\
\textbf{Current:} \tk{\textasciicircum{}GSPC} persistence = \textbf{0.9941} over 2{,}905
observations; excess kurtosis \textbf{15.8}, skew \textbf{−0.65}, Jarque-Bera
p ≈ 0 — decisively non-normal.

\subsection{Pillar 3 — Forex Pair Trading}
\textbf{Question:} Which currency pairs are tethered, and when is the gap tradeable? \\
\textbf{Method:} Engle-Granger cointegration across all pair combinations; for the
best pair, a hedge-ratio spread on \textbf{log prices}, standardised to a z-score,
with entry beyond ±2 and exit near 0, plus a mean-reversion half-life. \\
\textbf{Current:} USDCHF/USDJPY, p = \textbf{0.0075}, half-life \textbf{69 days},
hedge ratio −0.339, 91 historical signals.

\subsection{Also present — Black--Scholes}
European call/put pricing, the five Greeks, and a Newton/bisection implied-volatility
solver, served at \tk{/api/options/black-scholes}. It computes a \tk{vol\_verdict}
(options rich or cheap versus the GARCH forecast) but nothing consumes it yet.

\section{The Decision Engine}
This is the layer that turns three separate reports into one answer. The pillars are
untouched and still individually callable; the engine sits above them. \textbf{Seven
detectors} feed it: volatility regime, tail event, macro dislocation, pairs
opportunity, trend, breakout, and relative performance.

\subsection{Normalisation}
The detectors speak seven different direction vocabularies (``uptrend'',
``above\_model'', ``long spread'', ``compressed''\ldots). A polarity map collapses
them onto one bull/bear/neutral axis so they can be compared at all. Volatility and
tail readings are routed to a \textbf{separate risk axis}, so a volatility spike can
never fake a directional call. Each signal also carries a \textbf{reliability}
derived from its own statistics — cointegration p-value, macro R², GARCH sample
size — never invented.

\subsection{Fusion}
Weight \(w = \text{severity} \times \text{reliability}\), then:

\begin{keybox}
\begin{tabular}{@{}ll@{}}
\(\text{tilt}\)       & \(= (\text{bull} - \text{bear}) / (\text{bull} + \text{bear})\) \quad direction, \(-1..+1\) \\
\(\text{agreement}\)  & \(= 1 - \min(\text{bull},\text{bear})/\max(\text{bull},\text{bear})\) \quad how one-sided \\
\(\text{mass}\)       & \(= 1 - e^{-\text{total}/2}\) \quad saturating evidence weight \\
\(\text{conviction}\) & \(= \text{mass} \times (0.4 + 0.6 \times \text{agreement})\) \\
\end{tabular}
\end{keybox}

Strength beats count, nothing pins to 1.0 on noise, and a signal pointing the other
way actively \emph{lowers} conviction. This replaced an earlier
\(0.2 + 0.15n + 0.3\,\text{top}\) line that was dominated by signal count and clamped
to 1.0 the moment six of anything showed up.

\subsection{Tiered scan}
Price detectors run broad and cheap; one cointegration sweep serves the whole FX
basket; GARCH is cached on \tk{(ticker, last\_data\_date)} so it refits once per
trading day regardless of request volume. A detector that fails is recorded in
\tk{diagnostics}, never raised — one dead factor costs one signal, not the verdict.
Measured warm: feed \textbf{11\,ms}, per-asset \textbf{4.5\,ms}, off-universe cold
\textbf{0.9\,s}. Endpoints: \tk{/api/engine/\{feed,asset,narrate,status\}}, alongside
the unchanged per-pillar routes used for drill-down.

\section{The AI Layer — ``stats detect, the LLM explains''}
The model receives the computed detections as compact JSON and is instructed to use
only those numbers. It never feeds back into the fusion. Three things make that
verifiable rather than merely asserted:

\begin{itemize}
\item \textbf{Stance-first streaming.} The prompt demands a \tk{STANCE:} line before
the prose, so the model's labelled opinion lands after ≈10 tokens and the reasoning
streams beneath it instead of blocking for ≈20\,s.
\item \textbf{The model may disagree.} Its stance renders \emph{beside} the computed
stance, so a divergence is visible rather than hidden.
\item \textbf{A number guardrail.} \tk{unverified\_numbers()} checks every figure in
the narrative against the evidence supplied; anything unmatched surfaces in the UI as
a grounding badge.
\end{itemize}

Runtime is a local \tk{llama.cpp} server (Qwen3-4B) on an RTX 4050 via Vulkan, with an
in-process CPU fallback and a rules-only path if no model is up. Nothing leaves the
machine.

\section{Data Pipeline}
Yahoo Finance for prices, FRED for macro, cached as CSV so the app runs offline once
fetched. What we hardened, and why:

\begin{itemize}
\item FRED was returning \textbf{HTTP 403} — fixed with a proper request header, plus
a \textbf{DBnomics} mirror as fallback. The flaky 10-yr series was swapped for Yahoo's
\tk{\textasciicircum{}TNX}.
\item \tk{build\_macro\_dataset} is \textbf{fault-tolerant}: a failed factor is
skipped, not fatal.
\item \textbf{\tk{yfinance} is not thread-safe.} Concurrent \tk{yf.download()} calls
silently return one ticker's data under another's name — a threaded scan reproduced it
instantly (META/TSLA, JPM/GLD, \tk{\textasciicircum{}IXIC}/\tk{\textasciicircum{}DJI}
came back byte-identical). This was the root cause of the ``corrupted cache'' we had
previously only patched. Downloads are now serialized behind a lock; cached reads stay
parallel.
\item \textbf{Freshness:} the end date had been hardcoded to 2025-12-31 and caches
never expired, so the dashboard was reasoning over seven-month-old data. Now a rolling
end date plus an mtime staleness check, with a failed refresh falling back to the
stale copy rather than to nothing.
\item \textbf{\tk{run\_granger\_causality} was silently dead} — it passed a
\tk{verbose} kwarg removed in statsmodels 0.14, and a bare \tk{except} swallowed the
\tk{TypeError}, so it always returned zero results. Fixed.
\end{itemize}

\section{The Dashboard}
\begin{goldbox}
\textbf{Design rule: colour means direction, and nothing else gets to use it.}
Bull/bear are the only hues. Severity is bar length, source is a label, risk is a
segmented meter.
\end{goldbox}

\begin{itemize}
\item \textbf{Two-tier readout.} Every metric gives a plain-English word in the
primary slot, the exact figure beside it, and the mechanism in a hover tip. One
element serves a beginner and a trader; nothing needed to read the screen is behind a
click.
\item \textbf{Tilt gauge} — one instrument replacing four readouts: marker = balance
of evidence, band width = inverse conviction, so it reads like a confidence interval.
\item \textbf{Dissent is visible.} Signals opposing the verdict render under ``Pushing
the other way'' instead of being averaged away.
\item \textbf{Drill-down.} A signal's source badge jumps to the pillar tab that
produced it.
\item \textbf{Dual theme.} Light by default (it survives a projector), dark follows the
OS, three-state toggle. All 30 token pairings verified at ≥4.5:1 contrast in both.
\item \textbf{Type \& layout.} Archivo (variable) + JetBrains Mono; five sizes
replacing 32 ad-hoc values; bento grids that tile exactly at every breakpoint; signals
as a hairline list rather than a card grid.
\item \textbf{Shared ticker} across all five tabs via context — panels used to hold a
private \tk{useState("\textasciicircum{}GSPC")}, so switching tabs reset the asset.
\item \textbf{Skeletons} matched to the layout on first load, dim-in-place on refetch;
a session cache (stale-while-revalidate) removed the jank on tab switches.
\item \textbf{Status strip} reads \tk{/api/engine/status}: live / warming / offline.
The dot used to be hardcoded green, including when the backend was down.
\item \textbf{Time-range filters} (1M--All) on every time series, y-axis autoscaling to
the visible window.
\end{itemize}

\section{Testing \& Verification}
\begin{itemize}
\item \tk{backend/test\_engine.py} — 25 cases over the polarity map, fusion
invariants, ranking stability, reliability derivation, stance parsing, and the number
guardrail. These are the first tests in the repo.
\item An unknown ticker used to return \textbf{500} quoting an internal cache key.
\tk{data\_loader} now raises \tk{NoDataError} and the API answers \textbf{404} with a
readable message — one handler covers every endpoint, since all data access routes
through \tk{\_load\_or\_download}.
\item \tk{npm run lint} is clean. Design-hook detector: 8 findings → 0. Contrast
verified in both themes.
\end{itemize}

\section{What's Next}
The largest remaining gap is \textbf{statistical rigor}: the detectors are built but
several inferential claims are unvalidated — multiple-testing correction on the 990
cointegration tests, HAC/Newey-West errors on the autocorrelated monthly regression,
differencing the level-valued macro series, out-of-sample GARCH VaR with a Kupiec
test, and removing look-ahead bias from the pair-signal generation. After that:
wiring the Black--Scholes vol-mispricing detector into the engine, news-on-chart-click,
and a backtest that turns ``opportunities'' into measured evidence.

\section{How to Run}
\begin{itemize}
\item \textbf{Backend:} \tk{python -m uvicorn main:app -{}-app-dir backend -{}-port 8000}
(use the Anaconda interpreter on this machine).
\item \textbf{Local AI (optional but recommended):}
\tk{llama-server.exe -m <Qwen3-4B gguf> -ngl 99 -c 4096 -{}-port 8080}
\item \textbf{Frontend:} \tk{npm run dev} in \tk{frontend/} → open
\tk{http://localhost:5173}.
\end{itemize}
Without the AI server the app runs fine — narration falls back to in-process CPU
(≈5.7\,s) and then to a rules-only summary.
